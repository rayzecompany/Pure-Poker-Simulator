# Pure Poker Sim

Texas Hold'em against characters from six TV comedies, with an optional coach. A production of The Rayze Company.

## Download

Get the latest version from [Releases](../../releases).

- **Windows:** run `Pure-Poker-Sim-<version>-Windows.exe`. If SmartScreen warns, choose *More info → Run anyway*.
- **Mac:** open `Pure-Poker-Sim-<version>-Mac.dmg` and drag the app to Applications. The first time, right-click it and choose *Open*.
